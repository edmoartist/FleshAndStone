# FleshAndStone

Single-file HTML5 roguelite prototype.

## Current project file

- `toybox_catacombs_single_file_html_53.html`

## How to run

Open the HTML file in a modern browser.

Controls shown on the title screen:

- WASD to move
- Arrow keys or mouse to shoot
- E to interact, buy, or exit
- Space for shockwave
